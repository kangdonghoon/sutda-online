# 섯다 온라인

친구들과 링크 하나로 같이 하는 2장 섯다입니다. 칩은 가짜예요.

- **서버가 딜러**: 셔플, 패 보관, 족보 판정을 모두 서버에서 합니다. 각 플레이어는 자기 패만 받아요.
- **의존성 없음**: Node.js 기본 모듈만 씁니다. `npm install`이 필요 없어요.
- **로그인 없음**: 닉네임만 넣고 들어와요. 브라우저에 저장된 토큰으로 새로고침해도 자기 자리로 돌아옵니다.

## 로컬에서 실행

```bash
node server.js          # 또는 npm start
# → http://localhost:3000
```

같은 와이파이의 친구는 `http://<내 PC IP>:3000`으로 들어올 수 있어요.

포트는 환경변수 `PORT`로 바꿀 수 있습니다.

## 배포 (인터넷 링크로 공유)

### Render
1. 이 폴더를 GitHub 저장소로 올립니다.
2. Render에서 **New → Web Service**를 고르고 저장소를 연결합니다.
3. Runtime은 **Node**, Build Command는 비워두거나 `npm install`, Start Command는 `npm start`로 합니다.
4. 배포가 끝나면 `https://<이름>.onrender.com` 주소가 생겨요.

무료 플랜은 한동안 접속이 없으면 서버가 잠들어서 첫 접속이 느릴 수 있어요. 요금과 조건은 바뀔 수 있으니 배포할 때 확인하세요.

### Fly.io, Railway 등 Docker를 쓰는 곳
들어 있는 `Dockerfile`을 그대로 쓰면 됩니다. 컨테이너는 8080 포트로 뜹니다.

```bash
fly launch     # Dockerfile 자동 인식
fly deploy
```

## 노는 법

1. 닉네임을 넣고 **방 만들기**를 누릅니다.
2. **초대 링크 복사**를 눌러 친구에게 보냅니다. 링크는 `https://주소/#abcd` 형태예요.
3. 친구는 링크를 열고 닉네임만 넣으면 입장해요. 입장 화면의 열린 방 목록에서 들어와도 됩니다.
4. 방장이 **게임 시작**을 누릅니다. 사람이 모자라면 **봇 추가**로 채울 수 있어요.

방장이 나가면 남아 있는 사람 중 한 명이 자동으로 방장이 됩니다.

## 규칙

- 2장 섯다예요. 첫 장을 받고 베팅, 두 번째 장을 받고 베팅합니다.
- 족보: 38광땡 > 13·18광땡 > 장땡 ~ 1땡 > 알리 > 독사 > 구삥 > 장삥 > 장사 > 세륙 > 갑오 ~ 망통
- 특수패
  - 암행어사(4·7 열끗): 13·18광땡을 잡음
  - 땡잡이(3광·7 열끗): 1~9땡을 잡음
  - 구사(4·9): 상대 최고가 알리 이하면 재경기
  - 멍텅구리구사(4·9 열끗): 장땡 이하면 재경기
- 베팅: 다이, 체크/콜, 삥(판돈만큼), 하프(판의 절반), 따당(앞 베팅의 두 배). 한 라운드 레이즈는 최대 4번입니다.
- 같은 족보면 판돈을 나눠요. 올인한 사람은 자기가 건 만큼만 가져가는 사이드팟이 적용됩니다.
- 차례마다 30초 제한이 있어요. 시간이 지나면 체크할 수 있을 땐 체크, 아니면 다이로 처리됩니다.

## 구조

```
server.js          HTTP 서버 · 방 관리 · 게임 루프(봇, 타이머) · SSE 푸시
public/core.js     섯다 규칙 엔진 (순수 함수, 서버와 브라우저 공용)
public/index.html  화면
public/app.js      클라이언트 (EventSource로 상태 수신, fetch로 행동 전송)
test/core.test.js  족보 단위 테스트 + 무작위 1.8만 판 시뮬레이션
```

### 통신
- `GET /events?room&pid&tok`: Server-Sent Events. 상태(`st`), 채팅(`ch`), 강퇴(`kick`)를 보냅니다. 상태는 플레이어마다 따로 만들어지고, 자기 패(`me`)와 자기 차례일 때 가능한 행동(`h.lg`)만 들어 있어요.
- `POST /api`: `{ t, pid, tok, room, ... }`
  - `t` 종류: `create`, `join`, `act`, `chat`, `rebuy`, `leave`
  - 방장 전용: `start`, `bot`, `kick`, `ante`, `auto`
- `GET /api/rooms`: 열린 방 목록
- `GET /healthz`: 헬스 체크

### 신원
브라우저가 처음 접속할 때 `pid`와 비밀 `tok`을 만들어 localStorage에 저장합니다. 서버는 pid에 토큰의 해시를 묶어 두고, 이후 같은 pid는 같은 토큰으로만 쓸 수 있어요. 남이 내 자리로 행동을 보낼 수 없습니다.

## 한계와 다음 단계

- **상태는 메모리에만 있어요.** 서버가 재시작하거나 재배포하면 방과 칩이 사라집니다. 계속 남기려면 SQLite나 Redis에 저장하면 돼요.
- **서버 1대 기준이에요.** 여러 대로 늘리려면 방 단위로 같은 서버에 붙게 하는 처리(스티키 세션)나 공유 저장소가 필요합니다.
- 아무도 없는 방은 30분 뒤 자동으로 삭제됩니다.
- 회원가입이나 관리자 페이지를 붙이려면 이 위에 계정 테이블과 관리자 전용 API를 추가하면 됩니다.
